# Интерфейс помощника

Сотрудник стоит у рабочего места в ярко освещённом помещении или открывает телефон в офисе; ему нужен быстрый ответ без изучения меню. Интерфейс должен выглядеть премиально и спокойно, как сервис дорогого ресторанного бренда, но оставаться быстрым рабочим инструментом.

Цветовая стратегия: тёмная тема «изумруд + латунное золото», без бежевого. Фон `oklch(0.2 0.03 168)`, карточки `oklch(0.245 0.036 168)`, боковая панель темнее `oklch(0.155–0.2 0.03 168)`. Текст — светлая слоновая кость `oklch(0.95 0.014 85)`, вторичный `oklch(0.78 0.03 125)`. Золото `oklch(0.8 0.1 82)` — акценты, ссылки, курсив в заголовке, главные кнопки (с тёмным текстом), тонкие линии рамок. Кнопка голоса — золотая, как «Новый вопрос», с тёмно-изумрудным кругом микрофона. Вопрос пользователя — более светлый изумруд с золотой рамкой. Предупреждения — тёмно-янтарный фон со светло-золотым текстом.

Две гарнитуры: засечковая для заголовков и акцентов (Cormorant Garamond, файлы лежат в `knowledge/static/fonts`; курсив для выделения) и системная гротескная для интерфейса (Segoe UI). Шрифты с внешних серверов не подключаются: CSP разрешает только собственные ресурсы. Базовый размер 16px, заголовок главного экрана 66px на компьютере и 46px на телефоне. Мелкие подписи — капителью с разрядкой. Кнопки и поля с зонами нажатия минимум 44px, крупная кнопка диктовки. Скругления карточек 16–22px, мягкие многослойные тени. Иконки линейные, одного веса.

Компьютер: тёмная боковая навигация и центральная колонка не шире 840px; примеры вопросов — сетка карточек 2×2 с номерами. Телефон: верхняя панель, выезжающее меню и нижняя форма вопроса; примеры в один столбец. Видимая клавиатурная фокусировка, поддержка reduced motion. Анимация только для появления, записи, ожидания и раскрытия меню/диалогов.

Учебный режим отмечен постоянно. Результат текущего поиска называется фрагментом инструкции, а не сгенерированным ИИ-ответом. Выбор языка относится к диктовке; он не обещает перевод документов.
